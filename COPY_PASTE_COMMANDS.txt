TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

"fatal: could not read Username"
  → You need a GitHub personal access token
  → Get one: https://github.com/settings/tokens
  → Use it as your password (not your GitHub password)

"Repository not found"
  → Make sure you created the repo at https://github.com/new
  → Make sure it's PUBLIC
  → Wait a few seconds for GitHub to show it

"GitHub Pages says 404 Not Found"
  → Make sure you enabled Pages in Settings
  → Make sure Branch is "main" and Folder is "/(root)"
  → Wait 2-3 minutes for build to complete
  → Refresh browser

"Still can't see it after 5 minutes"
  → Go to: https://github.com/valentinaion/altamira-prototype/settings/pages
  → Check if there's an error message
  → Make sure repo is PUBLIC (not private)
