# ALTAMIRA Colombia Regenerative Investment Studio

## 🌿 Interactive Dashboard

This is a comprehensive investment analysis platform for regenerative and sustainable projects in Colombia.

### ✨ Features

- **Advanced Investment Analysis** - Professional-grade analytics tools
- **Dark/Light Theme Toggle** - Adaptive UI for all environments
- **ESG Metrics Dashboard** - Environmental, Social, Governance tracking
- **Interactive Filtering** - Real-time data analysis and filtering
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Professional UI** - Enterprise-grade user interface
